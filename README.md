# Shair

A peer-to-peer file sharing app for Android and iOS — send files between devices on the same network, without going through a server.

## Stack

Flutter · Dart

## Features

- Discover nearby devices on the local network
- Send and receive files directly between peers
- Transfer progress and history

## Running it

```bash
flutter pub get
flutter run
```
